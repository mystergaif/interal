# Website Auditor

Простой кроссплатформенный инструмент для базового аудита веб-сайтов, разработанный на JavaFX.

## Функциональность

*   Базовый поиск уязвимостей (SQL-инъекции, XSS).
*   Идентификация используемых библиотек и фреймворков (базовая).
*   Графический интерфейс в стиле терминала.

## Установка необходимых компонентов

### Для Windows

1. **Установка Java**:
   - Скачайте и установите Java Development Kit (JDK) 11 или выше с [официального сайта Oracle](https://www.oracle.com/java/technologies/javase-downloads.html) или используйте [OpenJDK](https://adoptopenjdk.net/).
   - Добавьте Java в переменную среды PATH:
     - Нажмите правой кнопкой мыши на "Этот компьютер" и выберите "Свойства".
     - Выберите "Дополнительные параметры системы" > "Переменные среды".
     - В разделе "Системные переменные" найдите и выберите переменную "Path", затем нажмите "Изменить".
     - Нажмите "Создать" и добавьте путь к папке bin в директории установки Java (например, `C:\Program Files\Java\jdk-11\bin`).
     - Нажмите "ОК", чтобы сохранить изменения.

2. **Установка Maven**:
   - Скачайте последнюю версию Maven с [официального сайта](https://maven.apache.org/download.cgi).
   - Распакуйте архив в удобное место (например, `C:\Program Files\Apache\maven`).
   - Добавьте Maven в переменную среды PATH:
     - Следуйте тем же шагам, что и для Java, но добавьте путь к папке bin в директории Maven (например, `C:\Program Files\Apache\maven\bin`).
   - Создайте новую системную переменную MAVEN_HOME:
     - В окне "Переменные среды" нажмите "Создать" в разделе "Системные переменные".
     - Введите имя переменной: `MAVEN_HOME`.
     - Введите значение переменной: путь к директории Maven (например, `C:\Program Files\Apache\maven`).

3. **Проверка установки**:
   - Откройте командную строку (cmd) и выполните следующие команды:
     ```
     java -version
     mvn -version
     ```
   - Если установка прошла успешно, вы увидите информацию о версиях Java и Maven.

### Для Linux/Mac

Для сборки и запуска проекта вам потребуется установлен Maven и Java 11 или выше.

## Сборка и запуск

### Для Windows

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/mystergaif/interal.git
   ```

2. Перейдите в директорию проекта:
   ```
   cd interal
   ```

3. Соберите проект с помощью Maven:
   ```
   mvn clean package
   ```
   Эта команда соберет исполняемый JAR-файл в директории `target`.

4. Запустите приложение:
   ```
   java -jar target\interal-0.1.jar
   ```

### Для Linux/Mac

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mystergaif/interal.git
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd interal
   ```

3. Соберите проект с помощью Maven:
   ```bash
   mvn clean package
   ```
   Эта команда соберет исполняемый JAR-файл в директории `target`.

4. Запустите приложение:
